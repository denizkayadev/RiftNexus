# RiftNexus

RiftNexus is a Real-time Data Processing Manager that leverages Intelligent Auto-scaling for workload optimization on a scalable Platform.

RiftNexus is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/RiftNexus.git`
2. `cd RiftNexus`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure RiftNexus, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
